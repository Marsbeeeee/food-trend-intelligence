# 小红书采集操作

配额、记录命令和停止条件遵循[采集标准](../collection.md)；本文件只记录页面操作经验。

1. 复用已登录的小红书标签。登录失效时只请求用户登录当前可见标签，不重复安装采集工具或新建多个会话。
2. 搜索配置关键词，并选择“视频”。小窗口下搜索框可能隐藏，需要先通过当前可见的搜索按钮展开。提交后等真实结果出现，再确认视频选项已选中；一次点击或地址刚变化不代表结果已完成切换。
3. 优先最多点赞；控件不可用或无法确认选中时记录综合。搜索条件按真实状态填写，即使详情后来确认是视频，也不能反推搜索页一定开启过视频过滤。
4. 结果可能虚拟化，滚动后当前DOM里的卡片数量不一定累计增加。读取当前可见卡片的完整带参数链接，与同日已存ID和attempt key比较；不要固定跳过“前20个DOM节点”，否则可能跳过全新的结果。
5. 登记attempt，再打开真实详情链接。确认原视频、标题、作者，等互动字段加载为数值后读取点赞、收藏、评论；缺失时有针对性复查，不用“收藏/评论”标签补0。页面改写到/explore/ID时保留实际完整地址，包括必要访问参数。
6. 收藏、评论和点赞读取详情自身的操作栏。页面可能还有大量评论点赞，不能把第一条匹配到的“赞”当视频总赞。每批保存后再回实际搜索入口，检查关键词与视频过滤是否保持，确认新结果已加载后再滚动。

上次可用定位线索：搜索选项#video的active状态；详情#noteContainer中的video、h1、作者资料链接、.date；详情操作栏.like-wrapper .count、.collect-wrapper .count、.chat-wrapper .count。上次视频总赞出现在同类匹配的最后一项，但只有当前DOM确认该位置属于视频操作栏后才能使用，不能永久盲取first或last。

“10万+”等保留原文，精确metrics留null；编辑时间不当首次发布时间。pipeline/collection.py负责最终字段检查和去重，浏览器采集不再临时定义另一套数据格式。
