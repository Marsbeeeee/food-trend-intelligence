# 阶段与职责

| 阶段 | Codex／采集人员 | Python | 人工决定 |
| --- | --- | --- | --- |
| 发现账号 | 搜索三平台与外部索引，访问主页核实，记录来源 | 验证字段和平台 URL、查重、报告计数 | 选择前可继续补证据 |
| 选账号 | 展示候选和可追溯依据 | 验证选择记录与账号 ID | 决定 selected／reserve／rejected／pending 并写理由 |
| 采视频 | 只采入选账号，连续日常样本与历史高表现分开 | 拒绝未入选账号视频、去重 | 确认采样口径、普通／高表现分组 |
| 内容对照 | 观看原片或读取可靠字幕，记录证据 | 同人物、同平台、同类型计算播放基线，生成对照草稿 | 检查观察、例外与推断 |

默认运行发现账号阶段并交付候选清单后停止。选人和视频分析不能默认为已经获得指令。脚本不自动登录、搜索、观看或猜测内容；搜索工具只能发现线索，主页核实要单独记录。

采集参数来自 config/collection.json，选人和比较来自 config/screening.json。不设账号流量门槛，低近期播放不是自动淘汰依据。历史表现也不自动证明面包内容或人设带来增长。

报告以情报和观察为主，仅给少量有依据的建议，不代替营销策划。所有原数据和报告继续保存在 data/；账号阶段与视频阶段使用不同报告版本。
